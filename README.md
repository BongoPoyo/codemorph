# Codemorph

Codemorph is a **cross-language CLI tool** for automatically converting variable and function names between different naming conventions. It follows **Unix philosophy**: simple, composable, and powerful.  

It supports **C, C++, Rust**, and more, with **automatic language detection** and in-place editing of source files.

---

## 🚀 Features

- Convert **variable names** and **function names** between different cases:
  - `snake_case`
  - `camelCase`
  - `PascalCase`
  - `kebab-case`
- **Language-agnostic**: works with multiple programming languages
- **Auto-detects language** from file extension
- **In-place edits** or output to stdout
- Cross-platform: **Linux, Windows, macOS**
- Can be integrated into **Neovim, VSCode, or other editors**
